# SOUNDCLOUD UPLOADER
This project was created for learning Kotlin purposes and is made fully by me with no AI help.
# THE IDEA
Soundcloud uploader is an Android app (iOS support will be added later) that lets you upload songs to soundcloud from youtube / soundcloud link (files also supported) and with option to use audio pitch, bass boost and song speed. the songs are stored in your local library and each song can be uploaded to your soundcloud accont from there.
